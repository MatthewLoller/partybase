# Partybase

An all-in-one RuneLite party plugin. It shows your party members' stats, inventory, equipment, and prayers in a side panel, with more party features being added.

Forked from [Party Panel](https://github.com/TheStonedTurtle/party-panel) by TheStonedTurtle (BSD 2-Clause, see `LICENSE`).

Partybase uses its own party message types, so it does not exchange data with members running the original Party Panel. Everyone in the party needs Partybase installed.

## Development

Requires JDK 11 or newer.

```
gradlew run
```

This launches RuneLite in developer mode with Partybase loaded. Log in through the Jagex account panel in the client sidebar.
